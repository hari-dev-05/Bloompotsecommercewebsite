# 🌿 Bloom Pots - Premium Flower Pot E-Commerce Website

A modern, fully responsive e-commerce website for selling premium handcrafted flower pots, built with React and Tailwind CSS.

## ✨ Features

### Core Functionality
- **Responsive Navigation Bar** - Sticky navigation with mobile menu support
- **Hero Section** - Eye-catching hero with call-to-action buttons and smooth animations
- **Product Catalog** - 8 premium flower pot products with high-quality images
- **Search & Filter** - Real-time product search and category filtering
- **Product Cards** - Beautiful card designs with hover effects, like functionality, and "Add to Cart" buttons
- **About Us Section** - Company information with feature highlights
- **Customer Testimonials** - Social proof with 5-star reviews
- **Newsletter Subscription** - Email capture form for marketing
- **Contact Form** - Full contact form with validation
- **Professional Footer** - Multi-column footer with social media links

### Design Features
- **Nature-Inspired Theme** - Green, beige, and white color palette
- **Smooth Animations** - Motion/React (Framer Motion) animations throughout
- **Hover Effects** - Interactive hover states on all clickable elements
- **Modern Card Designs** - Rounded corners and subtle shadows
- **Fully Responsive** - Optimized for mobile, tablet, and desktop devices
- **Premium UI/UX** - Clean, elegant, and user-friendly interface

## 📱 Responsive Breakpoints

- **Mobile**: < 768px (1 column product grid)
- **Tablet**: 768px - 1024px (2 column product grid)
- **Desktop**: > 1024px (3-4 column product grid)

## 🎯 Key Interactions

1. **Product Search**: Type in the search bar to filter products in real-time
2. **Category Filter**: Click category buttons to filter by type
3. **Like Products**: Click heart icon to favorite products
4. **Add to Cart**: Click "Add to Cart" button (functional UI ready for backend)
5. **Newsletter**: Submit email to subscribe
6. **Contact Form**: Fill and submit contact form
7. **Smooth Scrolling**: Click navigation links for smooth section scrolling
